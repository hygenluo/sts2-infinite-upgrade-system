# 无限升级系统 (InfiniteUpgradeSystem)

《杀戮尖塔 2》Mod：通过消耗点数对**卡牌 / 基础属性 / 能力 / 技能**进行无限升级。

> 点数规则的完整清单（实际代码行为）见 **[点数系统.md](点数系统.md)**。

## 功能

### 点数系统（摘要）
- 新局 **3** 点；战斗胜利：普通怪 **1~2**、精英 **5~6**、BOSS **25~27**（随机区间）
- 进入房间：问号房 **1~3**、商店 **1~3**、休息处 **2~4**
- **回退**：加错的加点可撤回，返还 **已付点数的 80%（下取整）**，例：10 → 8，7 → 5
- 点数本局有效，检查点（战斗开始/结束）自动保存，读档恢复
- 详细规则、玩家范围、随机源与多人一致性说明：见 [点数系统.md](点数系统.md)

### 卡牌操作（19 项，牌组子面板）
| 操作 | 点数 | 说明 |
|------|------|------|
| 升级卡牌 | 5 | 无限次升级（OnUpgrade 效果叠加） |
| 攻击 +1 / 格挡 +1 | 1 / 1 | 卡牌伤害 / 格挡永久 +1 |
| 抽牌 +1 / 重放 +1 | 7 / 7 | 抽牌数 / 重放次数 +1 |
| 耗能 -1 | 12 | 卡牌费用 -1（最低 0） |
| 添加/移除 消耗 | 12 / 15 | 消耗词条 |
| 添加 奇巧 | 7 | 奇巧（Sly）词条 |
| 添加/移除 保留 | 7 / 7 | 保留词条 |
| 添加/移除 固有 | 7 / 7 | 固有词条 |
| 添加/移除 虚无 | 8 / 8 | 虚无词条 |
| 添加/移除 永恒 | 10 / 15 | 永恒词条 |
| 新增附魔 | 12 | 多种附魔共存（合成附魔模型），达上限时替换最早的 |
| 从牌组删除一张牌 | 20 | 牌组操作 |

### 基础属性（8 项）
初始力量+1(10) / 初始敏捷+1(10) / 初始集中+1(15) / 初始覆甲+1(8) /
初始荆棘+1(10) / 初始人工制品+1(20) / 生命上限+1(5) / 充能球栏位+1(10)

### 能力（6 项）
每回合能量+1(30) / 每回合辉星+1(15) / 每回合铸造+5(15) /
格挡跨回合不消失(25) / 能量跨回合不消失(25) / 击败敌人获得20金币(7)

### 技能（43 项，全部本局有效，购买后显示 MAX 徽标）
按职业分 6 个标签页：通用 / 铁甲战士 / 静默猎手 / 储君 / 亡灵契约师 / 故障机器人。
- 计数类技能（每 4 张牌触发）在值列显示 **N/4** 实时计数
- 标签页显示该职业 **已拥有/总数**，分区头显示总进度
- **局内只读面板**：战斗中按 P 可打开查看（加号隐藏，顶栏显示「只读」徽标）

### 回退系统（v2.3 新增）
- **行内回退**：条目行左侧的 `[−]` 按钮（等级 > 0 时出现）可回退 1 级，旁边小字显示返还点数（`+8`）
- **回退分区**：主面板第 6 个分区，汇总所有可回退的加点（基础属性/能力/技能/卡牌操作），
  右侧摘要显示「可回退 N 项 · 可返还 M 点」
- **卡牌操作**回退流水会显示**具体卡牌名** + 「还有 N 次更早修改」（同一张卡按后进先出回退）
- **二次点击确认**：返还 > 0 时首次点击进入确认态（按钮转红、2.5 秒自动取消），避免误触损失 20%
- **不可回退**：升级卡牌（游戏降级接口会整卡重置）· 从牌组删牌（牌已不在）· 测试加点
- 战斗内（只读模式）不显示回退按钮

### 测试操作
点数 +1 / +5 / +10

### 悬浮窗（v2.4 新增）
- 局内屏幕**右侧边缘垂直居中**出现一个小胶囊按钮：上半是菱形图标、下半是**当前点数**
- **左键点击** → 打开 / 收起加点面板（等价于按 P）
- **按住拖拽** → 移动位置（位移超过 5px 才算拖拽，松手后位置被记住并限制在屏幕内）
- 非悬停时半透明（62%），鼠标移上去变不透明 + 金边高亮，不干扰游戏画面
- **只在本局内出现**：回到主菜单 / 读档界面自动消失，且不再拦截任何鼠标事件
- 选牌进行中点它会被忽略（避免打断选牌取消链路）
- 不想要可以在**模组设置**里关掉（见下）

### 模组配置（v2.4 新增）
游戏内「**模组设置 → 无限升级系统**」页面（主菜单与暂停菜单均可进入），当前提供：

| 配置项 | 默认 | 说明 |
|---|---|---|
| 显示悬浮窗 | 开 | 关闭后局内不再显示悬浮窗，仍可按 P 打开面板 |

- 配置**按存档独立保存**（RitsuLib `SaveScope.Profile`），改完**立即生效**，无需重启
- 悬浮窗位置也一并存在该配置里，换局/重启后位置不丢

## UI（v3：游戏原生字体 + 冷灰蓝/金配色）

- 按 **P** 打开/关闭（战斗中为只读模式），**Esc** 关闭；选牌界面按 **Esc** 取消选牌；
  也可点屏幕右侧的**悬浮窗**打开（v2.4）
- 主面板分区：**基础属性 / 能力 / 技能 / 牌组 / 回退 / 测试**（默认全部收起）
- **字体 = 游戏自带字体**：
  - 文本控件统一使用游戏自带的 `MegaCrit.Sts2.addons.mega_text.MegaLabel` /
    `MegaRichTextLabel`（自带语言字体替换与字号自适应）
  - 非 CJK 语言加载游戏主 UI 字体 `res://themes/kreon_regular_shared.tres`；
    中文/日文/韩文/俄文/泰文由游戏的 `FontManager` 自动替换（如 zhs → 思源宋体 / Noto Sans Mono CJK）
  - 模组不再打包任何字体文件（旧版自备 49MB 思源宋体已弃用，模组体积 49MB → 约 380KB）
- **配色取自游戏自身**：强调金 `#EFC851`、正文米白 `#FFF6E2`、面板冷灰蓝 `#20242B`、
  控件底色 `#363D4A`、危险红 `#FF5555`（`StsColors` + 游戏 StyleBoxFlat 实测值）
- **排版**：720×640 面板、顶栏（拖拽柄 / 标题 / 点数徽标 / 只读徽标 / 关闭）、
  分区头（矢量三角 + 标题 + 右侧摘要）、条目行（斑马纹 + 悬停高亮 + 成本徽标 + 圆形加号 + MAX 金徽标）、
  页脚快捷键提示
- 装饰性符号（三角/拖拽点/菱形/叉号/箭头）全部**矢量绘制**，不依赖字体是否有该字形
- 分区默认收起，展开状态跨开合保持；面板可拖拽，位置记忆
- 全局搜索（中英双语命中）：自动展开分区 + 滚动定位 + 金色高亮 + 空态提示
- 每项卡牌操作有**专属选牌提示**文案（中英双语）

## 多人联机

- **所有加点/卡牌操作走同步 action**（`NetUpgradeDataAction`，单一 INetAction 类型 → net-id 稳定），
  两端在同一 action id 上执行同一操作，各自从**每玩家 store**（按 NetId 分槽）读写
- **点数**：随机数走 RitsuLib 每玩家确定性 RNG 流；发点数遍历**所有玩家**（不按本地玩家分叉）
- **卡牌修改（v3 修复）**：修改记录按 **玩家 NetId + 卡牌身份** 分桶存储，
  读档时**两端都为所有玩家**重放（旧版只重放本地玩家 → 两端牌组不一致 → checksum 分歧）
- **加牌**：选中的 `ModelId` 作为 action 参数传输，两端添加同一张牌
  （旧实现两端各摇一次随机 → 加到不同的牌）
- 分歧排查工具：`DivergenceDiagnostics` 在 checksum 不匹配时转储两端状态

## 依赖
- 游戏本体（STS2）
- [BaseLib](https://github.com/Alchyr/BaseLib-StS2)（自动适配最新版，仅设最小值 v3.3.2）
- [RitsuLib](https://github.com/)（每玩家存档数据 + 确定性 RNG；manifest 声明 `STS2-RitsuLib` v0.5.11）
- **联机双方必须装齐同样的 mod 列表**（含 BaseLib / RitsuLib）

## 构建
```powershell
cd InfiniteUpgradeSystem
dotnet build -c Debug
```
自动部署到 `mods/InfiniteUpgradeSystem/`（DLL + manifest + 本地化 JSON）。

## 游戏内测试
1. 启用 BaseLib + RitsuLib + InfiniteUpgradeSystem
2. 开始新局（初始 3 点）
3. 检查屏幕右侧中部是否出现**悬浮窗**（菱形 + 点数）：拖动它、点它唤出面板、回到主菜单确认它消失
4. 非战斗中按 P 打开 UI，检查字体/配色/排版
5. 消耗点数进行加点；打完一场怪确认点数按区间发放
6. 进入战斗验证效果；战斗中按 P 打开确认只读模式
7. 存档退出再进入，确认所有修改恢复
