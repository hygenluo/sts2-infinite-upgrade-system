# 无限升级系统 (InfiniteUpgradeSystem)

《杀戮尖塔 2》Mod：通过消耗点数对卡牌和能力进行无限升级。

## 功能

### 点数系统
- 新局获得 5 点，击败普通怪 +1，精英 +5，BOSS +20
- 点数本局有效，存档/读档自动保存
- 检查点机制：战斗开始/结束时保存，未到检查点的修改退出后回滚

## UI（v2 属性面板式）
- 按 **P** 打开/关闭（仅非战斗中可用），**Esc** 关闭；选牌界面按 **Esc** 取消选牌（退款并回到子面板）
- **浅灰主题 + 思源宋体（MSDF）**，2K/4K 高分率下清晰锐利
- 五个分区默认收起：**基础属性 / 能力 / 技能 / 牌组 / 测试**，展开状态跨开合保持
- **牌组子面板**：整页切换，18 项卡牌操作，每项**专属选牌提示**（如「选择一张牌，令其攻击+1」）
- 条目行 = 名称 + 当前值 + 成本 + 加号；满级显示 **MAX 徽标**；点数不足置灰 + 点击抖动
- 全局搜索（中英双语命中）：自动展开 + 滚动定位 + 白色高亮 + 空态提示
- 面板拖拽位置记忆；动效：开合淡入/箭头旋转/悬停提亮/购买 +1 飘字/点数跳动

## 依赖
- 游戏本体（STS2）
- [BaseLib](https://github.com/Alchyr/BaseLib-StS2)（自动适配最新版，仅设最小值 v3.3.2）

## 构建
```powershell
cd InfiniteUpgradeSystem
dotnet build -c Debug
```

自动部署到 `mods/InfiniteUpgradeSystem/`。

## 游戏内测试
1. 启用 BaseLib + InfiniteUpgradeSystem
2. 开始新局
3. 非战斗中按 P 打开 UI
4. 消耗点数进行升级/加点
5. 进入战斗验证效果
